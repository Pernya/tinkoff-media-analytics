# Данные
Проект собирает публичные метаданные YouTube по запросам из `CONFIG`, затем сохраняет CSV в `media_analytics_output/`.
Сырые комментарии, cookies и выгрузки в репозиторий не включены. Для просмотра сохранённых агрегированных результатов сбор повторять не нужно.
Повторный сбор зависит от доступа к YouTube и Google Suggest, доступности роликов и ограничений сервисов; он может дать другой состав выборки.
